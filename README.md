# Keepsake

*for what words can't hold.*

DVB303 brand project, QUT Visual Communication. Joelle Lim, 2026.

- `/` the Keepsake website (EOYE 2026)
- `/app/` the Keepsake app: log memories by colour, texture, sound and place, spin the Memory Reel, shake the keychain, and keep days in a memory box. Kip the snail guides the way.

Static files only. Host anywhere; on GitHub Pages use branch `main`, folder `/ (root)`.
Everything a person keeps in the app is stored only in their own browser.
