# Keepsake

*for what words can't hold.*

A memory-keeping web app: log memories by colour, texture, sound and place, spin the Memory Reel, shake the keychain, and keep days in a wooden memory box. Kip the snail guides the way.

DVB303 brand project, QUT Visual Communication. Joelle Lim, 2026.

## Run it
It is one static page. Open `index.html`, or host the folder anywhere (GitHub Pages works: Settings → Pages → Deploy from branch → `main` / root).

Everything a person keeps (memories, videos, profile, box stickers) is stored only in their own browser.
